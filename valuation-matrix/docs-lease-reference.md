# Lease Extension Comparable Matrix — Gibsons Surveyors

Used for lease extension premium calculations under the Leasehold Reform, Housing and Urban Development Act 1993 (as amended by LAFRA 2024).

---

## Matrix Structure for Lease Extension

The lease extension matrix differs from the standard sales matrix. It establishes:

1. **Long lease equivalent value (LLEV)** — freehold or virtual freehold value of the flat
2. **Relativity** — percentage relationship between current lease value and LLEV
3. **Marriage value** — applies where unexpired term < 80 years
4. **Deferment rate** — typically 5% (post-Sportelli)
5. **Capitalisation rate** — for ground rent capitalisation

## Premium Calculation — Standard Formula

**Where unexpired term ≥ 80 years (no marriage value):**

> Premium = Ground Rent Capitalisation + Reversion

**Ground Rent Capitalisation:**
> GRC = Annual GR × YP (unexpired term + 90 years, deferment rate)

**Reversion:**
> Reversion = LLEV × PV (unexpired term + 90 years, deferment rate)

**Where unexpired term < 80 years (marriage value applies):**

> Premium = GRC + Reversion + 50% × Marriage Value

**Marriage Value:**
> MV = LLEV − (Current Lease Value + Freehold Value of Reversion)
> Current Lease Value = LLEV × Relativity%

## Comparable Matrix for Lease Extension

Build a sales comparable matrix (standard format) for the subject flat to establish LLEV. Apply:
- Leasehold adjustment (Category 13) to normalise all comparables to virtual freehold / 999-year term
- Use relativity table to convert short-lease sales to long-lease equivalent
- Note unexpired term for every comparable
- Flag comparables with term <80 years for additional scrutiny

Output: LLEV range (Low / High) — valuer to adopt a figure within that range.
